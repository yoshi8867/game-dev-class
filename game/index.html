던전 게임 만들기

완성된 던전 게임을 해 보고, 게임 속 요소를 정리한 사전을 읽은 뒤, AI에게 이 게임을 한 단계씩 만들게 하는 지시문을 직접 써 봅니다.

  1. 게임 해 보기

    방향키로 이동, Z로 회전 베기. 보스까지 가 보세요. 무엇이 어디에 있고 어떻게 움직이는지 눈여겨봅니다.

    플레이

  2. 요소 사전 읽기

    주인공, 적, 보스, 아이템, 보관함, 방의 이름과 위치, 하는 일. 숫자는 비워 두었으니 직접 정하세요.

    읽기

  3. 에셋 내려받기

    게임에 쓴 픽셀 그림 전부(zip). 압축을 풀어 내 작업 폴더에 넣고 AI에게 파일 이름을 알려 주세요.

    zip 받기
