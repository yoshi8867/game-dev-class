3. 세션과 컨텍스트

  • AI와 나누는 대화 한 묶음 = ________. 새 일은 새 ________에서 (새 술은 새 부대에)
  • AI가 그 세션에서 기억하는 지금까지의 대화 = _________
  • 질문 A, 답변 a, 질문 B, 답변 b 다음에 질문 C를 보내면 AI가 실제로 받는 것은 ___________________________. 모두 길이 100이면 토큰은 ________
  • 컨텍스트 ________: 필요 없어진 내용이나 틀린 정보가 남아서 AI가 헷갈리는 것
  • 컨텍스트 ________: 대화가 너무 길어져 앞부분을 흐릿하게 기억하는 것
  • ___________ 지금까지 쓴 토큰 / __________________ 컨텍스트가 얼마나 찼는지
  • ________________ = 되감기: 이전 대화로 돌아가기. 되돌릴 것 고르기: 대화만 · 코드만 · 둘 다

4. 메모장으로 지시하기

  • 지시는 메모장 파일에 쓰고, cmd 창에 드래그 앤 드롭 한 뒤 "읽고 진행해"
  • 좋은 점: 고치기 쉽다 · 다시 쓸 수 있다 · 내가 뭐라고 시켰는지 다시 읽을 수 있다
  • 지시 첫머리: 요청이 불분명하면 내게 충분히 질문한 후에 개발해

5. 직접 조절하고 세션 다루기

  • 크기·위치·시간 같은 숫자는 슬라이더를 달게 해서 내가 직접 조절하고, 값을 복사해서 AI에게 준다
  • ________________ 지금 세션에 이름 붙이기
  • ________________ 예전 세션 다시 열기
  • ______________ 대화를 비우고 새로 시작

6. 큰 게임은 단계별로

  • 먼저 단계별 계획을 세우게 하고, 한 단계씩 만들게 한다
  • 단계 사이마다 확인 · 수정 · 계획 변경이 가능하다
  • 단계가 끝날 때마다 __________________ 로 대화를 압축해서 오염·부패를 막는다
  • 어려운 일에는 큰 모델로: /model → opus

7. 내 게임 기획하기

  • 기획을 설명한 뒤, 불분명하거나 놓친 부분을 충분히 질문해 달라고 한다
  • 논의를 모두 마치고 내가 허락하면 단계별로 만든다
